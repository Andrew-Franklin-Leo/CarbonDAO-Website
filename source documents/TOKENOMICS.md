# Tokenomics Design

## Token Utility

* 1. Governance (CDAO Token)
	+ Voting rights
	+ Proposal creation
	+ Protocol parameter adjustment
* 2. Carbon Credits (CCR Token)
	+ Represents verified carbon credits
	+ Non-fungible tokens (ERC-721)
	+ Each token = 1 metric ton of CO2

**Update:** Introduced token burn mechanisms and inflation controls.
